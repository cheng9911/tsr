# 本轮实现审查

审查对象：新增几何、物理环境、执行器、批处理和测试文件；不修改旧轮次。

## 运行前发现并修正

1. 插入失败后回退到全局关节规划，可能偏离待比较的局部路径。
   已取消全部阶段的随机 IK/OMPL 回退，统一采用局部 screw 求解；失败保留。
2. NumPy/Torch 种子不能控制安装版本的原生 Pinocchio/OMPL 随机数。
   取消随机回退后，这条代码路径不再使用这些随机数。直通道仍检查实际输出是否一致。
3. 补充逐控制步的实测路径检查及穿越条件，避免仅凭终点成功认定正确穿过通道。
4. 物理环境与轨迹包装器来自相邻仓库，已纳入源码哈希与冻结快照。
5. 80 N 指 peg/socket 净合力；协议及报告明确它不是单点接触峰值。

复审未发现新的重要缺陷。一个小建议是进入阶段前额外记录初始穿越状态；
当前版本从首个控制步开始记录，可能保守地判定缺少入口见证。保持冻结版本不作事后修改，
后续版本可改进此处。所有探针和批次失败均保留。

## 验证方式

- 新增 11 项单元测试与 16 项相关现有测试；输出见 `verification_tests.log`。
- 400 个居中竖直姿态与独立 FCL 盒体碰撞结果交叉核验，见 `collision_crosscheck.json`。
- 批次源码/输入哈希、每格完整性、HDF5 状态数和净合力由汇总脚本复核。
- 成功轨迹从原始四元数重新计算通道坐标、穿越、横向误差、轴角、yaw 误差、
  以及考虑针片实际倾斜的顶部间隙，避免只信任在线成功标记。
