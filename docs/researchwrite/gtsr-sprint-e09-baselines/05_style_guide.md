# Style guide

- Language: Chinese, with exact API/model identifiers in English.
- Target reader: robotics/learning reviewer.
- Tone: conservative and engineering-feasibility oriented.
- Terminology: use “held-out response error”, “direct update baseline”, “diagonal
  response law”, and “descriptive comparison” consistently.
- Forbidden expressions: “proves universal superiority”, “causal”, “global
  observability”, and “black box loses” unless directly evidenced.
- Citation style: repository path plus frozen commit/hash where available.
