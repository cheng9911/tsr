# 任务约束不能唯一决定示教响应

## 三个对象

| 对象 | 含义 | 需要什么证据 |
|---|---|---|
| `Z_task(s,c)` | 环境 c、进度 s 下允许的位姿集合 | 几何、接触和动力学约束；成功与失败干预 |
| `X_pi(s,c)` | 策略 pi 从允许集合中选出的轨迹 | 明确控制器/示教者的原始轨迹 |
| `P_pi(s)` | 在指定模型族中拟合该策略如何响应 c | 相同策略的训练/留出预测及模型假设检查 |

任务要求 `X_pi(s,c) ∈ Z_task(s,c)`，但可能有许多这样的轨迹。
路径平滑、能耗、抓取便利、默认姿态或控制器目标都可能影响选择；本仓库能直接确认的是 solver 的默认 post_clear_yaw=0 和名义目标 yaw=0，不从轨迹猜测其他偏好。

## 一个精确的运动学反例

把位姿记为 `X=(R,p)`，释放后只关心位置 p 和插入轴 `a=R e_z`。
对任何允许的轴向角度函数 `b(s,c)`，定义：

`X_b(s,c) = X(s,c) H_z(b(s,c))`，其中 `H_z` 是无平移、绕物体自身 z 轴的旋转。

于是 `p_b=p`，且 `R_b e_z=R R_z(b)e_z=R e_z`。
完整位姿随 b 改变，但这两个任务量完全不变。若 b 依赖环境 c，环境响应也会改变。
因此仅靠这些任务量或最终成功标签，不能唯一确定自由方向的响应。

在本轮数值检查中，b 取每条示教的 yaw 干预量，keyed 只在 phase 2–3 施加，circular 全程施加。
±15°、±30° 四个 isolated 条件的自由阶段完整位姿误差均值为 11.781 mm-equivalent，任务代理为 0。
完整结果包括两个分支、三个 seed 和 mixed/isolated 两类输入，共 12 组。

这并未证明修改后的整条轨迹在碰撞、关节限制或动力学下可执行，也没有断言两个响应必然都属于同一个固定基底的对角参数族。
它证明的是：**这些任务条件不足以识别一般响应；模型约束与示教策略会补充额外选择。**

## 局部理论表述

若任务量为可微函数 `h(X,c)`，两条响应在同一点 X 的一阶差异 v 满足 `D_X h · v=0`，
任务量在一阶上就无法区分它们。对于等式任务约束，只有离开该零空间的响应分量被约束。
这是一阶陈述；碰撞等不等式约束还需要考虑可行方向，不能直接用一个全局线性投影代替。

因此不建议写“P 恢复任务真实响应”。更准确的说法是：

> 在指定关系坐标、参数族和正则化下，P 估计给定示教策略的条件响应；任务约束界定哪些响应差异影响任务量，允许集合中的剩余选择体现策略偏好。

用词上，`P_task` 若要成为唯一对象，就必须额外指定选取原则，例如最小能量响应或某种规范；单独给定 Z 不够。
本轮没有引入这类选取原则，也没有验证当前 Pdiag 在所有自由方向都可辨识。

## 现有实验证据的强度

1. 入口 ±30° 匹配/错配干预改变通过与阻塞，支持测试条件下对入口姿态的任务依赖。
2. post-clear ±30° 各有成功执行，说明默认回到 0° 不具有唯一必要性。
3. 反例检查证明完整模仿损失会惩罚任务代理看不见的轴向差异。
4. 这些证据尚未直接比较两种完整示教控制器在相同多 seed、多物体条件下学到的 P，不能宣称控制器偏好已被完整分离。

数据来自一个按预期结果自适应重试的采集器。报告全部 7 次尝试；不把选出的 6 个有效 probe 当作随机独立样本。
环境 success 检查位置误差 <12 mm、插入轴夹角 <0.15 rad；yaw 不进入成功判据。
这项源码事实与两个实际非零 yaw 成功执行相互支持，但不扩展成任意 yaw 均能成功。

## 下一轮能真正区分两者的实验

### 同一任务，改变示教策略

固定几何、干预 context、初始状态和预算；设置三种 post-clear 控制策略：返回固定角度、保持进入时角度、返回另一个固定偏置角度。
在各自训练数据上拟合 P，保留共同测试 contexts。零干预 baseline 应与策略匹配，同时额外报告统一锚点下的响应，避免混淆策略名义轨迹与响应差异。

预期检验对象不是“哪个 P 更接近手工真值”，而是：策略改变后 P 的自由方向是否变化、通过/成功是否保持、受约束阶段的误差是否稳定。
若换策略使任务成功下降，不能把该变化直接归类成无关偏好。

### 同一策略，改变物理任务约束

在匹配的任务条件下分别保留/去掉入口键部，或改变实际释放位置。用 raw clearance/contact 记录释放，不能用预置 phase 标签宣布已释放。
检查必要姿态响应是否随约束改变，以及示教控制器是否确实利用释放后的自由度。

### 每个条件保留所有尝试

预先固定重试次数、失败定义和评价预算；记录规划失败、执行阻塞、超时、成功，禁止只选符合预期的尝试。
先用额外开发数据估计配对差与 seed 变异，再确定独立确认实验的样本量。当前 n=3 不能支持精确功效估计。
最终同时报告物理成功/接触结果、任务量偏差、完整示教误差和 profile 差异；不能用一个总分替代。
