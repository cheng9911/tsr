# 最小显式基线与变螺距：决策节点一

状态：开发验证协议；在运行本批结果前固定。旧数据只读，新输出必须使用不存在的目录。

## 问题与贡献边界

本轮检验 G-TSR 在相同映射、信息、坐标采样分布、导数信息和求解器下增加了什么。
映射、Jacobian、投影和连接能够正确工作，只算一致性与实现可靠性证据。
不以包装、命名、解析导数相对自动微分的速度差作为独立的新算法贡献。

任务为 `T(psi, eta) = Trans(0,0,b+h*psi+a*psi²+eta) Rz(psi)`，
`psi ∈ [0,1] rad`，`eta ∈ [-rho,rho] m`，`b=.12 m, h=.04 m/rad`。
固定 `a = [-.08,-.02,0,.02,.08] m/rad²`、`rho=[0,.0005] m`。
旋转残差权重 `.02,.10 m/rad`；随机种子 `930501,930502`。
`a=0` 是恒定螺距对照；角度区间小于 pi，避免绕角与主值分支混淆。
固定左侧刚体变换用于检查坐标系处理；右侧工具变换保持单位阵，以保留独立投影参考。

## 三种实现

1. `gtsr_analytic`：新增实验 chart，调用未修改的生产 GTSR 和生产投影器。
2. `explicit_analytic`：直接映射适配器，不构造 GTSR，提供相同解析导数，调用相同生产投影器。
   这是隔离区域包装开销的控制，不宣称独立规划算法。
3. `explicit_autodiff`：独立 PyTorch float64 映射和自动微分 body Jacobian；相同域、目标和投影器。
   PyTorch CPU eager 实现；其开销不能归因于表示方法的固有复杂度。

三种实现均使用参数域均匀采样；不称其为流形体积均匀采样。
每参数组合/种子匹配 256 个样本、16 个 Jacobian 查询、32 对连接端点。
投影每权重/种子用 8 个查询：带内、域端点外、轴向扰动及随机查询。
投影起点固定为域下角、上角和中点，不提供参考解；生产求解器的其余参数保持默认。
同一查询随机排列三种实现的执行顺序；计时前单独记录导入及预热。

## 独立检查与指标

- 采样：解析真实区域检查、匹配位姿差、参数分布；不把重复样本当独立场景。
- 导数：独立的变换中心差分 body Jacobian；报告绝对误差。
- 投影：共同 weighted principal SE(3)-log 残差，分别记录目标、带外违例、域违例、KKT 标志、时间。
- 参考：对本任务的同轴查询消去 eta，枚举分段四次目标的全部边界与驻点。
  多项式根先在 float64 求出，再用 mpmath 60 位精度细化和计算目标。
  属于有完整候选推导的高精度数值参考，不是区间算术认证。用独立密网格复核最小值；
  根细化失败、非有限值或复核不符均标记参考未验证，不用于宣称全局正确。
- 正确投影阈值：与可信参考的目标距离差绝对值 ≤ 1e-7 m（旋转已按权重缩放）；
  区域带外违例 ≤ 1e-10 m、角度域违例 ≤ 1e-10 rad。
  求解器 success 与参考正确性分别统计，缺失和异常保留在分母。
- 连接：比较坐标线段映射与位姿的轴向/角度线性插值。后者连续残差是二次式，
  在端点及导数零点求最大绝对值；独立密采样仅用于复核，不冒充连续证明。
  坐标映射连接的 eta 是凸组合，故整段在带内；这一性质三种实现共享。
- 分段线性/恒定螺距近似：K=1,4,16,64，中心线最大误差 `|a|/(4K²)`，
  只作误差—分段数标尺，不标为 DSS，也不把该近似误差算作其他方法的规划失败。
- 记录映射、Jacobian、自动微分内部映射调用次数；IK 和碰撞调用数均为零且明确标注。
  本轮没有机器人、障碍、关节路径，也没有端到端成功率结论。

## 决策规则

若三种实现的正确性与通用算子行为相同，且差别仅为包装/导数后端开销，
结论为“尚未发现可区分的技术增量”。暂不扩大曲面、机器人、DSS/CCA 集成。
随后列出具体失败模式及候选机制，先定义能证伪该机制的小实验。
若出现差异，先检查输入、采样、初始化与求解器是否匹配，再判断是否值得第二阶段。
不根据本批开发结果作统计显著性或跨任务泛化结论。
