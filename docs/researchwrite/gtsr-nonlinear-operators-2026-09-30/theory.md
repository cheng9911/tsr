# 本轮验证所用的独立参考

以下推导限定在同轴变螺距区域，不是一般 SE(3) 投影的全局保证。

## 1. 区域与导数

令 `f(psi)=b+h*psi+a*psi²`，
`Phi(psi,eta)=Trans(0,0,f(psi)+eta) Rz(psi)`。
进度域 `[0,Q]` 为实区间，不能因为包含 Rz 就将 psi 声称为周期变量：位移没有相同周期。
本批 Q=1 rad，正带宽有两维参数；rho=0 时第二个坐标固定。

采用 `[v,omega]` 顺序的 body Jacobian：

```text
J = [[0,              0],
     [0,              0],
     [h + 2*a*psi,    1],
     [0,              0],
     [0,              0],
     [1,              0]].
```

其两列在整个区间线性独立。rho=0 只是可行域退化，不是该二维映射的 Jacobian 秩退化。
固定左变换不改变 body Jacobian；本批右变换为单位阵。
a=0 时该映射与恒定螺距 PoE 加轴向 slack 一致。
a≠0 的瞬时螺距 h+2*a*psi 随 psi 变化，所以不是单个恒定螺距螺旋。
这不排除多轴、共享坐标或外部耦合构造；不据此主张整个 DSS 框架被严格包含。

## 2. 投影候选完整性与数值可信范围

查询为相同左变换下的 `Trans(0,0,zq)Rz(tq)`，且所有 `|psi-tq|<pi`。
使用生产 weighted principal-log 目标，在这类同轴变换下精确简化为：

```text
F(psi,eta) = (f(psi)+eta-zq)^2 + w^2*(psi-tq)^2.
eta*(psi) = clip(zq-f(psi), -rho, rho).
F_reduced(psi) = max(|f(psi)-zq|-rho,0)^2 + w^2*(psi-tq)^2.
```

连续函数在闭区间取得最小值。所有可能的最小点包含在：

1. psi=0,Q；
2. 分段切换点 `f(psi)=zq±rho`（二次方程）；
3. 轴向残差为零段内的 `psi=tq`；
4. 两个外侧段的驻点 `(f(psi)±rho-zq)f'(psi)+w²(psi-tq)=0`（三次方程）。

在所有候选上计算真实的 reduced 目标后取最小值，额外加入不属于对应分段的驻点不会低估最小值。
本实现先 float64 枚举多项式根，再以 mpmath 60 位精度细化及计算目标，最后用20,001点密网格复核。
`verified` 表示数值检查通过；初始根来自浮点且没有区间包围证明，因此不能称为严格数值认证。
若参考异常/未验证，应报告未知，不计为某个方法的错误。

## 3. 连续连接的独立检查

端点为 `(psi0,eta0)`、`(psi1,eta1)`。坐标线段映射中的 eta 是端点 eta 的凸组合，
只要端点在盒域内，整个映射连接都满足轴向带约束。这是三个实现共享的构造性质。

轴向位移和旋转角都线性插值时，连续残差为：

```text
e(t) = eta0 + (eta1-eta0)*t + a*(psi1-psi0)^2*t*(1-t),  0<=t<=1.
```

最大绝对残差由两个端点和区间内的导数零点确定。此式验证整段的模型带约束，
没有验证碰撞、机器人关节连续性、跟踪误差或物理接触。
另行2001点残差检查及17个位姿映射检查仅作实现复核，不替代上述连续推导。

## 4. 分段近似

在长度为 Δpsi 的一个段内，用端点弦线近似二次中心线，最大轴向误差为 `|a|Δpsi²/4`。
等分 K 段时为 `|a|Q²/(4K²)`。它是指定构造的误差标尺，不是任意螺旋组合的复杂度下界。
如果还允许宽度 rho 的 slack，整段对真实中心线的误差上界须加上 rho；
不能给近似中心线加满真实带宽后自动声称所有样本都可行。
