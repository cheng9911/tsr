# 用“特例、严格扩展、表示紧凑性”组织 G-TSR 证据

这里的 GSR 按本仓库 G-TSR 理解。结论是：在仓库明确规定的合法单 TSR 范围内，
TSR 是 G-TSR 的精确特例。包含关系由构造证明承担，实验验证实现及应用收益。
本目录增加独立验证结果，不修改任何已有实验结果或冻结证明。

## 1. 特例关系：如何得到完全相同的区域

传统 TSR 的区域为

\[
\mathcal R_T=\{T_0\operatorname{Trans}(x,y,z)R_z(\psi)R_y(\theta)R_x(\phi)T_e:
 (x,y,z,\phi,\theta,\psi)\in\kappa(B_w)\}.
\]

G-TSR 的定义为

\[
\mathcal R_G=\{T_0\Phi_{\mathcal C}(u)T_e:u\in\mathcal Z\}.
\]

选择 canonical chart，并令坐标域等于规范化后的传统边界，就逐项恢复传统 TSR。
因此包含的是**表示族**：每个合法单 TSR 都存在一个表示同样位姿集合的 G-TSR。
`κ` 处理圆周角区间，合法性与边界条件见原证明。

- [构造证明 P1](../../gtsr_expressivity_proofs.md)。
- 实现入口：`src/tsr/gtsr/region.py` 的 `GTSR.canonical`。
- 本轮重跑 85 项相关测试，包含非单位左右 frame、角度环绕、退化边界、欧拉奇异点、兼容接口等。
- 另外记录 5000 个随机合法 TSR 的逐点前向误差：最大平移误差 **0 m**，
  最大旋转误差 **0 rad**（这次浮点实现计算结果）。这支持实现兼容，不替代普遍性证明。
- 上轮直通道 36 格中，同预算同种子的六种方法具有完全相同的状态和动作轨迹；均为 5/6 成功。
  共同失败保留，说明兼容性不等于控制器不会失败。

## 2. 严格扩展：哪些运动需要额外表达能力

取非零有限螺距生成元 `ξ=[0,0,h,0,0,1]`，其运动满足 `z=hq`、`yaw=q`。
一个 G-TSR 的单生成元即可精确表示此曲线。
原证明 P2 通过螺距在坐标变换下不变、切向方向与区域维数，
证明它不能由一个传统独立坐标边界 TSR 精确表示，包含关系因此严格：

\[
\mathfrak F_{\mathrm{single\ TSR}}\subsetneq\mathfrak F_{\mathrm{GTSR}}.
\]

这一定理范围是单区域。原 TSR 工作还包含 TSRChain、投影与完整规划器，
不能把单 TSR 的结论自动推广到整个传统系统。
参见 [Berenson 等，2011，原文 §4–5](https://personalrobotics.cs.washington.edu/publications/berenson2011task.pdf)。

## 3. 新补实验：同样完整覆盖，需要多少个传统区域

使用上轮已知螺旋任务的保守带 `|yaw-0.8s|≤0.03 rad`，`s∈[0,1]`。
保持完整覆盖，沿进度等分为 K 段，每段使用紧致的独立深度/yaw 边界。
全部方法共享随机数；每方法每通道 10 个种子、每种子 1000 个样本。
2 通道 × 9 方法 × 10000 = **180000 个样本**。

| 表示 | 区域数量 | 螺旋通道实测带内比例 | 理论期望 |
|---|---:|---:|---:|
| 单 TSR | 1 | 6.66% | 6.98% |
| TSR 并集 | 4 | 23.15% | 23.08% |
| TSR 并集 | 16 | 55.08% | 54.55% |
| TSR 并集 | 64 | 82.76% | 82.76% |
| TSR 并集 | 128 | 90.77% | 90.57% |
| TSR 并集 | 254 | 94.96% | 95.01% |
| TSR 并集 | 512 | 97.24% | 97.46% |
| TSR + 显式耦合修正 | 1 + 修正规则 | 100% | 100% |
| G-TSR | 1 | 100% | 100% |

这里的覆盖率由构造保证；“带内比例”是采样有效率，不能称为覆盖率。
直通道所有方法的样本均在带内，符合退化预期。不同于上轮采样比例的细小差异来自新的预定种子。

对该规定的等分紧包围盒构造，理论为

\[
p_K=\frac{0.06}{0.8/K+0.06},\qquad
K_{p\ge0.95}=\left\lceil\frac{0.8\times0.95}{0.06\times0.05}\right\rceil=254.
\]

254 是该构造达到 **期望 95%** 有效率所需的最小整数盒数，不保证每次有限样本比例超过 95%。
它也不是任意非均匀划分、任意 frame 或任意 TSRChain 的全局最优复杂度下界。
此处记录区域数量，不把它等同于最优存储量、全部参数量或运行时间。
显式修正基线保留：它说明已知耦合也可以在区域表示之外实现。

## 4. 论文中应突出什么

建议将论点写为：

> G-TSR 无损包含传统单 TSR，并能通过生成元直接编码有限螺距等耦合运动。
> 对所测试的已知耦合约束带，单个 G-TSR 即可精确采样；
> 传统独立边界区域需要增加区域数量，或引入显式耦合处理，才能取得相近的有效采样率。

证据安排：

1. **兼容性**：构造证明 + 随机/边界差分 + 直通道轨迹一致。
2. **严格扩展**：有限螺距反例证明 + 数值螺距与非周期性检查。
3. **表示紧凑性**：本轮区域数量—有效率表，以及上一轮不同螺距/容差曲线。
4. **操作可用性**：固定控制器的螺旋孔执行；上轮 G-TSR 为 6/6，多区域和显式修正也可持平。

这比单独比较最终成功率更直接回应“推广了什么”。
已有计时仍必须保留：G-TSR 当前实现并未快于强基线。
此证据也不证明任务约束能从示教中被辨识，不建立方法在文献中的首创性。
