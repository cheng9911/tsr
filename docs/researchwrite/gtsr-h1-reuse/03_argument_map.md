# Argument map

## Scientific tension

已有受控transfer结果可节省重复工作，但其评分量由共享selector生成，不能单凭小误差证明物理迁移。
核心问题：在不重训source、不重复采集的前提下，哪些既有结果可纳入论文，H0接入还缺哪些检查？

## Central thesis

保留原有5对目标及全部baseline为开发级受控证据；通过来源锁定与显式gate接入提高可审计性，
把独立物理可迁移性留为可证伪且未完成的实验命题。

## Supporting arguments

1. 复用S1/S4的已存结果而不是再跑：避免计算重复，也避免悄悄重选source或subset。
2. 用S2/S3区分数据生成、预测方法与任务评价：nominal变化不等于独立动力学变化。
3. 用S6补basis/phase/support拒绝合同；只改变验证的显式程度，不宣称增加独立样本。

## Counterarguments

- small error可能来自合成selector共享，而非跨物体物理规律：明确受控数据边界。
- transfer与scratch差异可能来自nominal预算：保留预算不同的历史比较，禁止称纯law消融。
- 5pairs共享3个source，多个seed评分量相同：不做独立seed显著性检验或合并伪样本。
- strict support会拒绝部分isolated：按历史`Rx Ry Rz`约定如实记录10个越界，不扩宽边界来让测试变绿。

## Final move

先锁定retrospective复用协议及H0桥接缺口；新的physical H1需另设独立ground truth与执行方案，
不能以“又跑一批同collector seeds”补足。
