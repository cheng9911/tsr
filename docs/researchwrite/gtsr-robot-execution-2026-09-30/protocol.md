# Panda 物理执行桥接实验

2026-09-30，在本轮执行结果产生前写定。配置以 protocol.json 为准。

## 研究问题与范围

将冻结的环境响应转换成 Panda 实际执行的目标，检验离线预测是否转化为任务成功。
在传统 TSR 能精确表示的区域上交叉比较 TSR/G-TSR 与 Frame/Pdiag。
两种几何表示应得到相同目标，这是兼容性对照，不作为耦合几何优势证据。
这一阶段完成后，仍需耦合物理场景、多区域/约束修正强基线、连续碰撞检查和独立确认。

## 冻结设计

- 复用既有 keyed/circular PhysX 环境、Panda 和抓取流程。兄弟仓库保持只读。
- 每个任务使用 source seed 20260818 的第12号 N=30 训练子集。Pdiag 读取既有生产 artifact；
  Full affine 与 TP-GMM SE(3) 使用完全相同训练轨迹。没有目标执行数据再拟合。
- 五种响应均作用于共同解析名义路径。直接预测器取 `A(c)=Y(c)Y(0)^-1`。
  这是把已有响应迁移到共同解析名义路径的开发实验，不是原生预测轨迹复现。
- 核心四组 `TSR/PoE G-TSR × Frame/Pdiag`，另加 TSR+Fixed/Full affine/TP-GMM SE(3)。
- 两个任务 × 四个预定 context × 三个新执行 seed × 七个方法，共168次计划尝试。
  同任务、context、seed 下初始条件配对；方法顺序固定随机化。每单元只尝试一次。
  冒烟运行用另一 seed，单独目录保留，不并入正式开发批次。
- 新 seed 不足以构成独立确认，本轮属于开发。三个 seed 是随机初始化重复；
  四个 context 也是固定条件，不能宣称随机任务总体上的泛化或 n=168 的独立样本。

## 控制与信息权限

固定名义插入深度序列与阶段进度。所有响应同样获得预定的环境 context 和已知名义参考系。
执行前核对实际 socket pose 与该 context 一致；这是已知环境变化的实验，未加入感知噪声。
阶段和进度由执行程序指定，不读取未来、不根据完整轨迹长度评分，也不是 Sprint G。
所有方法同样使用实测 peg/TCP pose 修正当前抓持偏差。
响应模型不能读取 goal pose、clearance、success、接触力来生成目标；这些只用于结果记录和统一停机。

每个目标区域以预测位姿为中心，平移半宽0.5 mm。声明自由阶段允许自身轴±30°。
名义中心优先，IK失败时使用最多两个配对随机区域坐标。TSR 和 PoE 使用完全相同的坐标。
这些局部区域是控制目标容差，不声称已经从数据学得全部任务可行集合 Z。
计划先尝试 screw，再在剩余2秒预算内尝试 RRTConnect，超过预算的规划结果不执行。
抓取阶段使用相同流程和预算；失败不得从分母删除。PhysX 碰撞/接触一直启用。
底层规划器未接入完整场景碰撞几何，本轮不声称连续无碰撞规划。

## 结果和失败

主要结果为环境原有物理 success（位置误差<12 mm 且插入轴误差<0.15 rad）。
该成功定义允许轴向自由旋转，不是完整姿态跟踪。另报告最终距离、轴误差、
最大 peg-socket 净接触力、控制步数、规划耗时、墙钟时间、求解/超时/力阈值失败。
净接触力的范数不是各接触点力大小之和。100 N 为统一开发停机阈值，不作安全性保证。
保存每次尝试的动作、实测位姿、关节状态、标签、规划候选、退出原因、输入及源码哈希。
崩溃或超时保留为失败，不能用仅存活的 HDF5 计算成功率。
