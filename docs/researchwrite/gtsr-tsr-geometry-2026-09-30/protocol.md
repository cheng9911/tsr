# TSR 与 G-TSR：几何直接比较协议

本轮由“开始新一轮的工作”启动，承接 TSR 特例关系与直接比较的讨论。
本文件与 protocol.json 在本轮数值结果生成前写入。它是合成开发实验，不能作为真实任务确认实验。
当前打开的 Sprint G 只处理在线阶段估计；本实验另开目录，不修改其阈值、范围或确认集。

## 研究问题

在已知几何、相同有限容差下，精确表达耦合约束是否减少无效采样，并改善同一简化规划器的预算内求解率？
增加传统 TSR 的区域数量，或者提供显式耦合修正，是否能缩小差异？

## 固定任务族

状态为 `(x,q,z)`，对应 SE(3) 位姿 `Trans(x,0,z) Rz(q)`。
任务可行域为 `x∈[-12,12] mm`、`q∈[-0.5,0.5] rad`、`|z-hq|≤epsilon`。
这是具有非零容差的螺旋约束带，避免用零测度曲线让盒式采样必然失败。
h 与 epsilon 的全部组合、20 个算法随机 seed、样本数和预算在 JSON 中冻结。
h=0 是传统 TSR 可精确表达的对照；不只运行有利于 G-TSR 的耦合场景。

简化规划在这个三坐标子空间中进行。障碍物是 JSON 指定的两个 `(x,q)` 配置矩形，
需要左右绕行；并非真实物体网格碰撞。起点与终点为 x=0、q 两端、z=hq。
固定可行绕行路径只用于确认问题可解，不向规划器提供。

## 比较方法

| 方法 | 构造与额外信息 |
|---|---|
| 单 TSR | 全 q 范围的最紧 canonical 包围盒，z 边界为端点 hq 再扩展 epsilon |
| K 个 TSR 的并集 | q 等分为 K=4、16、64 段；每段采用同样的最紧包围盒；覆盖整个任务带 |
| 独立坐标 TSRChain | 一个 x/z 平移区域接一个 yaw 区域；作为此具体 chain 的对照，不代表全部 chain 的最优能力 |
| G-TSR PoE | x 平移、螺旋生成元 `[0,0,h,0,0,1]`、z 容差平移，三个有界坐标精确生成任务带 |
| TSR 加耦合修正 | 单 TSR 提议后令 z=hq+clip(z-hq,−epsilon,+epsilon)；提供已知约束的强参照，记录修正比例和幅度 |

所有方法都获得相同 h、epsilon 和边界。差别在表示和采样/修正方式，不比较几何学习能力。
K 并集不是 TSRChain。修正方法不是裸 TSR 表示，也不称作全 SE(3) 最近点投影。
不将某个较弱 chain 构造的结果推广到全部 TSRChain。

## 两层评价

1. **集合与采样：** 对共同随机流测量提议有效率、完整任务带覆盖率、共同查询分布上的错误接受率。
   与精确积分得到的有效率比较；并集只增加近似复杂度，不能通过缩小覆盖范围取得较高精度。
2. **规划：** 相同 RRT、目标偏置、最近邻度量、步长和连续边检查。先检查提议是否满足真实任务与障碍物，
   再扩展；全部提议计入预算，包括拒绝和目标偏置。预算是提议数，不是等运行时间。
   记录 128/512/2048 提议内是否找到解、耗时、节点数、检查次数、路径约束违反和长度。

使用配对算法 seed。20 个 seed 是同一合成场景的算法随机重复，不是20个物体/物理执行 seed。
报告每个 h×epsilon 的结果、失败和预算敏感性，不挑最好任务汇总成普遍优势。
首次成功即停止的实际消耗与预算分别保存；失败不可从均值分母删除。

## 实现与验证

快速采样映射必须对照仓库实际 TSR、TSRChain、GTSR/PoEChart 前向映射验证，避免另造不等价模型。
解析集合判断统一使用严格几何容差，避免 legacy TSR 的 EPSILON=1 mm 与本实验小容差混用。
RRT 在简化配置空间做线性边；任务带为仿射约束，端点满足即可保证整边满足，矩形障碍使用连续线段相交检查。
另用密集路径采样核验最终结果。h=0 时成对采样和路径结果应一致。

为控制成本，对所有方法使用经前向映射验证的向量化采样器；运行时间不用于比较生产 API 的速度。
源码、协议、环境及结果保存 SHA。本轮不改动生产模型或历史螺旋示例。

## 理论与主张边界

本轮新增的采样公式只覆盖上述坐标系下的紧致盒及等分并集，不是任意 frame、任意 chain 的最优下界。
既有严格包含证明仍是单区域族的数学结论。
本轮没有 Pdiag 拟合、阶段观察器、关节空间 IK、机器人动力学或接触执行。
完成后可以讨论合成约束下的采样和规划收益；真实操作收益和几何×响应的四组消融仍需独立实验。
