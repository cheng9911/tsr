# 紧致 TSR 并集的采样有效率

令角区间长度 L>0，任务带为 `q∈[a,b]`、`|z-hq|≤epsilon`，epsilon>0。
x 是相同且独立的有界坐标，以下面积比中相消。

## 命题

把 q 等分成 K 个区间，每个区间用包含整段任务带的最紧轴对齐 `(q,z)` 盒表示。
等概率选择盒，再在盒内均匀独立采样，则样本满足真实任务带的概率为

`p_K = 2 epsilon / (|h| L / K + 2 epsilon)`。

证明：每盒 q 宽度为 d=L/K，z 宽度为 `|h|d+2epsilon`。对每一个 q，
真实带的 z 截面长度都是 `2epsilon`，且被该盒完整包含。因此有效面积为 `2epsilon*d`，
盒面积为 `d*(|h|d+2epsilon)`。所有盒具有相同面积，q 内部互不重叠，故并集的比率相同。

给定目标采样有效率 `0<tau<1`，该构造所需盒数满足

`K >= |h| L tau / [2 epsilon (1-tau)]`，并向上取整、至少取1。

同一构造的最大超出容差量为 `|h|L/K`。有限 K 通常仍包含任务带以外的点。
覆盖率一直为1，因此有效率提高来自增加区域数量，不来自遗漏允许运动。

G-TSR 取三个 PoE 生成元：x 平移、螺旋 `(v=h e_z, omega=e_z)`、z 平移。
坐标 `(x,q,e)` 的乘积得到 `Trans(x,0,hq+e)Rz(q)`，令 `|e|≤epsilon` 即精确生成任务带，
所以约束有效率为1。TSR 加显式耦合修正也可达到1，但增加了独立于盒表示的约束处理。
h=0 时 p_K=1，传统单 TSR 与 G-TSR 的该任务区域相同。

## 限定

这是规定构造下的精确积分结果，不是所有传统 TSR/TSRChain 的最优复杂度定理。
有效率不等于规划成功率：障碍物、连通性、采样密度和规划预算都可能改变规划结果。
均匀采样原坐标再修正会改变输出分布，不能自动宣称与 G-TSR 均匀坐标采样相同。
