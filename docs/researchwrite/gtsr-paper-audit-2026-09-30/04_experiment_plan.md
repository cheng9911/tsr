# G-TSR 后续实验设计

当前优先级：先统一指标和观测语义，再判断对角响应是否足够，最后进行物理迁移。
以下是开发实验设计；确认性实验须在方法、门槛和采样规则冻结后另行登记。

## 第一阶段 统一响应与任务评价

**问题：** 世界动作残差的坐标依赖是否改变拟合方法与控制方法的比较？

1. 查找并核验已有 36 个完整 source artifacts。若缺失，固定原数据、子集、优化器和软件版本
   确定性重建，分别保存 theta、名义轨迹、名义 frame、优化状态和 SHA。不能把只有 alpha grid
   的 artifact 伪装成完整可部署模型。
2. 对同一批预测同时计算：历史世界动作残差、关系局部动作残差、位姿预测残差。
   当前脚本已完成 Frame/Fixed 控制的这一步，Pdiag 仍需完整 artifact。
3. 增加被动世界平移/旋转检查；改变坐标后局部响应和位姿残差必须一致。
4. 将按阶段重采样的曲线指标与原始时间轴指标分开。若保留原时间轴，所有方法使用同一物理事件
   和同一时间配准，不能由各自预测阶段移动评分边界。
5. 保留旧协议结果；新指标及门槛写成新版本。装配间隙、接触容差和控制误差决定其工程解释。

**输出：** 2 arms×3 seeds×6 generators×全部方法的同预算配对表、坐标一致性检查、完整模型 artifact。
**失败含义：** 若主要收益依赖世界原点或只存在于某一种残差，收窄主张并解释原因。

## 第二阶段 区分任务必要约束与示教策略偏好

**问题：** 识别到的是任务必需响应，还是 canonical solver 的运动选择？

在同一个任务可行域中，让两种 controller/teacher 采用不同但都有效的 yaw 冗余策略。
锁定接触几何、干预和阶段事件，对比它们的任务可行性与学习到的 alpha。

- key-clear 前：通过碰撞/几何约束独立检验错位是否不可行。
- key-clear 后：分别执行继续跟随 yaw 与保持 yaw 的候选动作，独立检查两者是否都可行。
- 若两者都可行但 profile 不同，报告“控制策略条件下的响应规律”；不能称为任务唯一规律。
- 若希望选择最小运动响应，先定义并固定运动代价或控制偏好，再评价该偏好下的学习。

**输出：** 区域可行性、运动代价、profile 差异和自由度处理后的预测误差。
**失败含义：** 若 law 随任意 teacher 偏好改变，其迁移对象必须包含 teacher/代价语义。

## 第三阶段 检验结构选择而非只增加模型容量

**问题：** 数据是否支持对角响应假设？

比较 Fixed、Frame、共享标量、当前对角模型、稠密局部算子、同预算 Context RBF，以及配置正确的
TP-GMM。所有学习方法共享训练干预、名义轨迹信息、阶段和目标侧 calibration 预算。
TP-GMM 具有方向性统计结构，不以“标量 Frame”代替。

开发集上做三种轴间结构：可分离、两轴耦合、基误对齐。首先使用独立生成真值的受控合成系统，
再在具有真实约束/接触求解的任务上验证。训练只用 mixed 干预，评价同时包含独立 held-out mixed
与 single-axis 干预；明确各自是否位于训练 Log 支持范围内。

评价包括：完整响应误差、任务位姿/可行性、训练数据量曲线、拟合失败与拒绝比例、跨 seed 的差异。
当前 20-seed 合成实验已证实跨轴耦合是对角类的失败模式，但没有验证生产 RBF 拟合器在这些条件下的表现。

**决策：** 若对角模型只在预设对角真值下有效，将其限定为有检验机制的结构假设；
若独立物理数据中也稳定存在该结构，再强化物理解释。不能因为拟合不好就默默扩大模型后仍称同一方法。

## 第四阶段 独立物理迁移

**问题：** 在给定且可审查的关系对应下，冻结源 law 能否用于新的物理目标？

优先选择同一关系家族中的几何变体，例如改变 key-clear 深度或入口几何，但保持对应语义可以独立定义。
至少设置：正确对应目标、错误阶段对应、超出支持范围目标；最后两者作为拒绝或失效对照。

- 在观察 target 性能前固定基对应、阶段事件对应与支持范围。
- 源 law 冻结；target nominal calibration 对所有方法使用同一预算。
- 目标响应来自独立物理求解或机器人执行，并由独立几何/接触/成功检查评价。
  不能把 transferred alpha 写进目标轨迹生成器，再用该轨迹验证 transfer。
- 对比 frozen transfer、同预算 target scratch、目标数据量增加的 scratch、Fixed/Frame 和适用的任务参数化方法。
- 报告闭环成功、最大接触力、约束违反、终点误差、运动代价和 abstention；保留方法失败。
- 区分干预条件、execution seed、对象几何三个层级。相同评分轨迹的重复回放不能充当独立物理重复。

**失败含义：** 合同匹配但物理响应失效，说明代数对应不足以保证规律迁移；这是需要报告的结果。

## 第五阶段 确认性实验

沿用既有 G00 的开发/确认分离原则，但在指标修订后另立版本：

1. 冻结主要指标、主对照、实验单位与任务级 margin 锚点。
2. 用独立工程需求和开发误差确定有意义效应，进行功效或精度模拟；样本量不能只取 exact test
   能计算的最低 seed 数。
3. 固定样本量、种子清单、缺失替换、方法失败、零差值处理与多重比较。
4. 若使用 sign-flip 进行均值推断，明确交换性/对称性假设；精确枚举本身不保证任意误差分布下有效。
5. 全部冻结后生成新执行数据，一次性评价；不将现有三个开发 seed 重新标记为确认集。

本轮没有生成确认集，也没有替作者选择未经任务公差支持的显著性门槛。

## 最小可投稿主线

先完成第一至第三阶段，可形成“有适用范围和失效诊断的任务响应表示”论文。
若标题或摘要主打跨任务迁移，第四阶段必须成为核心证据。
在线阶段估计与完整机器人系统是另一个可拆分研究问题，不应同时成为这篇论文尚未满足的前提。
